# Socle OS

Projet de système d'exploitation pour développeurs débutants et futurs analystes en cybersécurité.

- `preview/index.html` : aperçu interactif de l'interface (ouvrir dans un navigateur, aucune installation).
- `docs/ARCHITECTURE.md` : choix techniques, comparaison Windows / macOS / Linux, feuille de route et risques.

À essayer dans l'aperçu :

- Terminal : `aide`, `explique rm`, `dir`, `rm -rf /`, `sudo installer htop`, `sudo installer crack-office`, `scan 8.8.8.8`
- Labo Cyber : trouver l'IP de l'attaquant dans `/lab/logs/auth.log`
- Sécurité : retirer une permission, ouvrir le pare-feu, revenir à l'image système précédente
